One-time setup for the app owner Google sign-in isn't switched on in this build yet. The app owner does this once; after that everyone just clicks Sign in with Google.
  1. Open Google Cloud, New project. Name it Still and click Create.
  2. Turn on the Google Calendar API (click Enable).
  3. Set up the consent screen: app name Still, your email, audience External. Then under Audience, add your own Gmail as a Test user.
  4. Go to Create OAuth client. Type: Web application. Under Authorized redirect URIs, add this exact address: loading…
  5. Click Create, copy the Client ID (it ends in .apps.googleusercontent.com) and paste it here:
Google will warn that the app isn't verified. That's expected for your own test app: click Continue. Still only asks to read events.
